# AddisReel 🇪🇹
Native Android short-drama app dedicated to licensed Ethiopian short movies.

## Status
Initial Android MVP: cinematic dark UI, vertical feed scaffold, Discover, Library, Premium, episode navigation and video playback support. No licensed catalog or payment credentials have been connected.

## Build
GitHub Actions > Android APK > Run workflow; download the debug APK from the completed run's artifacts.

## Payments
Planned ETB checkout through a licensed Ethiopian payment gateway. Never unlock episodes based solely on client callbacks; verify provider signatures and server-side payment status. Google Play billing policies must be reviewed before publishing digital-content payments.

## Content
Only stream content with distribution rights. Sample entries are placeholders.
